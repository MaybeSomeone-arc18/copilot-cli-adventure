# The Lantern of Moonfall

A simple command-line choose-your-own-adventure game written in Python using only the standard library.

## Requirements

- Python 3.8 or newer

## Run the game

From the directory containing `adventure.py`, run:

```bash
python adventure.py
```

On some systems, use:

```bash
python3 adventure.py
```

Choose options by entering the corresponding letter when prompted. Your decisions and inventory determine the ending.

## How this was made

adventure.py and the first draft of this README were generated by GitHub Copilot Chat from one prompt. I ran it with scripted inputs to check all three endings are reachable.
